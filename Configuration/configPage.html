Content Hider Settings

Per-user movie, show, and collection hiding across Web, Mobile, and TV clients using each user's private Magic Playlist (tagged with __is_content_hider_playlist).

Default name when creating a user's private playlist (default: [{username}: Hide Content]). Playlists are tracked via the __is_content_hider_playlist tag, so users can rename their playlist freely.
